\section{Einleitung}

Ziel dieses Projekts ist der Aufbau einer einfachen
Temperaturüberwachung mit einem Raspberry Pi 4 Model B
und einem digitalen Temperatursensor.

Das System erfasst in regelmäßigen Abständen die
Umgebungstemperatur und speichert die Messwerte zur
späteren Auswertung.

Ein solches System kann beispielsweise zur Beobachtung
eines Serverraums, eines Gewächshauses oder eines
Hobbyraums eingesetzt werden.

Der Raspberry Pi ist ein kompakter Einplatinencomputer.
Das Modell 4 besitzt einen 40-poligen GPIO-Anschluss,
über den externe Sensoren angebunden werden können.

\section{Systemaufbau und Komponenten}

\subsection{Hardware}

Für einen einfachen Versuchsaufbau werden folgende
Komponenten benötigt:

\begin{itemize}
    \item Raspberry Pi 4 Model B
    \item Digitaler Temperatursensor DS18B20
    \item Anschlussleitungen und Steckbrett
    \item microSD-Karte
    \item USB-C-Netzteil
\end{itemize}

\subsection{Systemarchitektur}

Der Sensor misst die Umgebungstemperatur und
überträgt die Daten an den Raspberry Pi.
Dieser verarbeitet die Messwerte und speichert
sie zur späteren Analyse.

\subsection{Software und Ablauf}

Die Messwerterfassung kann mit Python umgesetzt werden.
Ein Programm liest den Sensorwert in einem festen
Zeitintervall aus und speichert ihn in einer CSV-Datei.

Der Ablauf besteht aus vier Schritten:

\begin{enumerate}
    \item Sensor initialisieren und Verbindung prüfen.
    \item Temperaturwert auslesen.
    \item Messwert mit Zeitstempel speichern.
    \item Vorgang nach einer Wartezeit wiederholen.
\end{enumerate}
